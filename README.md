# AI-Assisted Data Migration Consultant

An independent project exploring how agentic AI can assist data-migration
consultants with data discovery, source-to-target mapping, data-quality
analysis, validation, reconciliation, and migration-risk reporting.

## Objective

Develop a human-in-the-loop migration assistant that recommends mappings and
data-quality rules while keeping final decisions with the consultant.

## Planned Workflow

1. Source-data profiling
2. Source-to-target mapping
3. Data-quality rule recommendation
4. Human approval
5. Transformation and validation
6. Reconciliation
7. Migration-risk reporting

## Technology Stack

- Python
- SQL
- Pandas
- DuckDB
- FastAPI
- Streamlit
- LLM tools
- ChatOllama
- Pytest
